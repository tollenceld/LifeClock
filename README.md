# 刻度 · LifeClock

一块安静、私密的个人时间仪表。

刻度以「出生／此刻／预计终点」构成人生时间区间。主体验采用「时间织幅」：过去已经织入，未来仍是未织入的经线，此刻把两者连在一起。四种尺度使用同一个织面和排版，不再使用钟表两面或翻面交互。

## 功能

- 人生、日、月、年四种时间尺度，保留独立人生入口和日月年／设置胶囊
- 生之始与死之终同时显示八位小数天数；两组数字共享同一采样时刻，分别累计和倒数
- 织口的纵向位置按真实区间进度映射，当前百分比、出生日期与预计寿命持续可见
- 织口上的小点展示当前一分钟的真实位置，并标注「这一分钟」；一分钟结束后在两端换向，连续起织，不加速整个人生进度
- 四尺度复用同一织面，侧边颗粒分别为半小时、自然日、月份、人生生日节点；约 0.55 秒空间插值缩放
- 全部页面遵循用户选择的暖纸／石墨外观，没有按生死强制切换主题
- 设置概览与首次引导使用同一静态织面，生日、预计寿命、换算、外观与轻触反馈保留
- 日月年刻点以小标记融入织面；相邻刻点通过菜单编辑
- 刻点集支持搜索、新增、编辑、删除；历史每周记录可保留、删除或主动转换
- 支持 Dynamic Type、减少动态效果、减少透明度和 VoiceOver；不自动播报实时更新
- 本地 JSON 备份导出、预览与确认恢复；错误文件拒绝，恢复失败回滚
- 关于页面解释计算依据与隐私；存储打不开时提供重试，不抹除数据
- 无账号、无广告、无网络请求、无第三方 SDK

生日、预计寿命、偏好和刻点保存在设备本地；主动导出的位置由用户选择，备份未加密。死之终依据用户设定的预计寿命计算，并非死亡预测。达到设定终点后，已度过继续增长，尚余归零。

- Swift 6
- SwiftUI 与 Canvas
- SwiftData

- XcodeGen
- 最低系统版本：iOS 18

## 本地开发

### 环境

- Xcode 27（项目仍保留 iOS 18 最低部署版本）
- XcodeGen
- 支持 iOS 18 或更高版本的模拟器

### 生成工程

仓库已经包含可直接打开的 `Kedu.xcodeproj`。修改 `project.yml` 后，可以重新生成工程：

```sh
xcodegen generate
```

### 构建

```sh
xcodebuild \
  -project Kedu.xcodeproj \
  -scheme Kedu \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' \
  build
```

### 测试

```sh
xcodebuild \
  -project Kedu.xcodeproj \
  -scheme Kedu \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' \
  test
```

核心测试覆盖日历区间、共享生日锚点、DST、相界互补关系与推进、尺度插值、时间颗粒及历史规则。UI 测试覆盖双读数同时存在、真实进度、实时数字、四尺度导航、设置与刻点、前后台恢复、大字号与到期状态。

本轮测试结果、运行证据和验证边界见 [设计与验证记录](DesignReview/README.md)。

辅助功能标签与动作已检查，尚未开启系统 VoiceOver 验证实际朗读；iOS 18 材质降级代码编译通过，但未在 iOS 18 运行时实测。

## 隐私

刻度不自动联网、收集或上传个人数据。主动导出的系统文件可保存在用户选择的本地或云端位置；系统备份受设备设置控制。App 不申请通讯录、日历、照片、位置、健康、麦克风、相机或通知权限。

隐私声明与上架材料位于 [`StoreAssets`](StoreAssets/README.md)。
